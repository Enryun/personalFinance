# Vola locales

Locale packs translate the complete product page, FAQs, alt text, and navigation without an English fallback for visible product content. The shared adapter expands these compact packs into the page’s content shape. English and Vietnamese retain their existing copy.

Facts must stay consistent: live transcription is on-device; imported-media transcription may use Apple’s network service; Gemini receives text only with permission; AI requires sign-in, internet, and credits; plans and device/language support limit availability. Interface language does not establish speech/translation support.

These translations require native editorial review before claims of native-market validation. No search volume, local ranking, or AI recommendation results are implied. Privacy/terms and developer walkthrough destinations remain English.
